-- AskIt database setup
--
-- Existing installations must run:
--   supabase/migrations/001_security_and_performance.sql
--
-- The previous schema allowed the anon role to modify every row. Those policies have
-- been removed. Legacy content that cannot be mapped safely to an auth.users UUID is
-- retained as read-only instead of assigning it to a guessed owner.
--
-- Authentication setup:
--   1. Enable Google in Supabase Authentication > Providers.
--   2. Add http://localhost:3000/auth/callback and the production callback URL under
--      Authentication > URL Configuration > Redirect URLs.
--   3. Set NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY.
--
-- The versioned migration is the canonical schema source.
